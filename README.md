<summary><b>🎲 Мини-задача по SQL — проверь себя</b></summary>
<br>
<p><b>Задача.</b> Таблица <code>sales(store_id, check_id, amount)</code>: один чек это несколько строк. Посчитай средний чек по магазинам и оставь только те, где он выше среднего по сети.</p>
<details>
<summary>👉 Показать решение</summary>

```sql
WITH per_check AS (
    SELECT store_id, check_id, SUM(amount) AS check_amount
    FROM sales
    GROUP BY store_id, check_id
),
per_store AS (
    SELECT store_id, AVG(check_amount) AS avg_check
    FROM per_check
    GROUP BY store_id
)
SELECT
    store_id,
    ROUND(avg_check, 2) AS avg_check,
    ROUND(AVG(avg_check) OVER (), 2) AS network_avg
FROM per_store
WHERE avg_check > (SELECT AVG(check_amount) FROM per_check)
ORDER BY avg_check DESC;
